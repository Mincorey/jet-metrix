# Список ручных проверок функционала (ПРОВЕРИТЬ.md)

В данном файле ведется единый реестр задач для ручной проверки функционала системы JetMetrix перед релизом.

---

## 📌 Раздел «Динамика выдачи в ВС» (от 17.09.2026)

- [ ] **1. Главное меню приложения**:
  - [ ] Открыть стартовую страницу.
  - [ ] Проверить наличие новой кнопки «Динамика выдачи» строго под кнопкой «Аналитика».
  - [ ] Убедиться, что стиль кнопки, шрифт, отступы и анимация нажатия полностью соответствуют соседним кнопкам.

- [ ] **2. Переход и интерфейс раздела**:
  - [ ] Нажать кнопку «Динамика выдачи».
  - [ ] Убедиться, что открывается страница с заголовком «Динамика выдачи в ВС» и бейджем «Авиатопливо».
  - [ ] Проверить кнопку «На главную» — при нажатии происходит возврат в главное меню.
  - [ ] Проверить кнопку «Скриншот» — скачивается графический файл высокого разрешения с отчетом.
  - [ ] Проверить кнопку «Обновить» — данные перезагружаются из базы данных.

- [ ] **3. Фильтры периодов**:
  - [ ] Проверить переключение всех 6 кнопок фильтров:
    - [ ] «Вчера» (24 часа)
    - [ ] «Неделя» (7 дней)
    - [ ] «Месяц» (30 дней)
    - [ ] «3 месяца» (90 дней)
    - [ ] «Полгода» (180 дней)
    - [ ] «Год» (365 дней)
  - [ ] Убедиться, что активная кнопка подсвечивается зеленым изумрудным цветом с анимированным индикатором.

- [ ] **4. График №1 (Выдача в литрах)**:
  - [ ] Отображается плавная изумрудная кривая с градиентной заливкой.
  - [ ] При наведении курсора / касании пальцем отображается всплывающая подсказка (тултип) с датой, временем, объемом в литрах, массой в кг, плотностью и номером ТЗА/талона.
  - [ ] Горизонтальная ось отображает время суток (для «Вчера») или календарные даты.
  - [ ] Вертикальная ось отображает объем в литрах (тысячи литров, например 5k, 10k).

- [ ] **5. Информационный фрейм под Графиком №1**:
  - [ ] Карточка «Период» — отображает точные даты (например, 16.09.2026 или диапазон дат).
  - [ ] Карточка «Операций в ВС» — число заправок за период.
  - [ ] Карточка «Выдано топлива (л)» — суммарный объем в литрах.
  - [ ] Карточка «Средняя плотность» — средневзвешенная плотность партий керосина (г/см³).
  - [ ] Текстовое пояснение снизу сформулировано понятно и содержит итоговую сводку за выбранный период.

- [ ] **6. График №2 (Выдача в килограммах)**:
  - [ ] Отображается стильная кривая цвета индиго (фиолетово-синяя) с градиентом.
  - [ ] Интерактивный тултип отображает массу в кг и сопутствующие данные.
  - [ ] При смене периодов кривая плавно перерисовывается с анимацией.

- [ ] **7. Информационный фрейм под Графиком №2**:
  - [ ] Содержит карточки: Период, Операций в ВС, Выдано топлива (кг), Средняя плотность.
  - [ ] Текстовое пояснение снизу содержит понятное резюме по массе и плотности топлива.

- [ ] **8. Темы оформления**:
  - [ ] Проверить корректность отображения графиков и текста в светлой теме.
  - [ ] Переключить на темную тему (иконка луны/солнца вверху) — графики, карточки и текст остаются контрастными и легко читаемыми.
